# 问题一：有界角度误差下的交会定位区域及其直径

## 1. 问题分析

测向机在检测点给出的示向度并非精确射线，而是与真实方位角相差不超过 `1°` 的读数。因此，一次观测对应的可行集合不是直线，而是夹角为 `2°` 的闭角扇形。多个检测点对同一干扰源的定位区域，是这些角扇形的公共部分。

本问需要解决两个问题：

1. 由若干检测点坐标和示向度构造多边形定位区域，并计算区域内任意两点距离的最大值。
2. 判断以该最大距离为直径的圆是否一定能够覆盖定位区域。

整个推导只使用有界误差条件，不假设误差服从正态分布，也不以测得方向线的最小二乘交点代替完整定位区域。

## 2. 符号说明

| 符号 | 含义 |
|---|---|
| `S_i=(x_i,y_i)` | 第 `i` 个检测点 |
| `theta_i` | 在 `S_i` 处测得的示向度 |
| `delta=1°` | 示向度最大绝对误差 |
| `X=(x,y)` | 干扰源可能位置 |
| `e(alpha)` | 方向为 `alpha` 的单位向量 |
| `Omega_i` | 第 `i` 次观测对应的角扇形 |
| `Omega` | 所有观测的公共定位区域 |
| `D` | 定位区域直径 |
| `C*`、`r*` | 最小覆盖圆圆心及半径 |

定义二维向量叉积：

```text
[a,b] = a_x b_y - a_y b_x
```

方向单位向量为：

```text
e(alpha) = (cos(alpha), sin(alpha))
```

## 3. 单次观测的半平面表示

第 `i` 次测量的真实方位角满足：

```text
theta_i - delta <= beta_i <= theta_i + delta
```

令：

```text
l_i = e(theta_i-delta)
u_i = e(theta_i+delta)
q_i = X-S_i
```

由于扇形宽度 `2delta=2°<180°`，点 `X` 位于从下边界 `l_i` 逆时针旋转至上边界 `u_i` 的扇形中，当且仅当：

```text
[l_i,q_i] >= 0
[q_i,u_i] >= 0
```

展开后得到两个线性半平面约束：

```text
(-sin(theta_i-delta), cos(theta_i-delta)) · X
    >= (-sin(theta_i-delta), cos(theta_i-delta)) · S_i

( sin(theta_i+delta),-cos(theta_i+delta)) · X
    >= ( sin(theta_i+delta),-cos(theta_i+delta)) · S_i
```

这种写法直接使用正弦和余弦，不需要分别讨论示向度是否跨越 `0°`，因而避免了角度区间在 `359°` 附近产生的分支错误。

## 4. 多边形定位区域

记第 `j` 个半平面为：

```text
H_j = {X | a_j x + b_j y >= c_j}
```

若有 `n` 次观测，则交会定位区域为：

```text
Omega = intersection(H_j), j=1,...,2n
```

半平面的交仍为凸集。因此，只要 `Omega` 非空且有界，它就是一个凸多边形或退化的线段、点。

### 4.1 顶点枚举算法

本题观测次数通常不大，可采用透明、稳定的顶点枚举算法：

1. 枚举 `2n` 条边界直线中的任意两条。
2. 若两直线不平行，则求其交点 `P`。
3. 将 `P` 代回全部 `2n` 个半平面约束。
4. 若 `P` 满足所有约束，则它是定位区域的候选顶点。
5. 对候选点去重，并使用单调链算法求凸包，得到逆时针排列的多边形顶点。

两个边界方程：

```text
a_1 x+b_1 y=c_1
a_2 x+b_2 y=c_2
```

在行列式 `Delta=a_1b_2-a_2b_1` 非零时，交点为：

```text
x = (c_1b_2-b_1c_2)/Delta
y = (a_1c_2-c_1a_2)/Delta
```

枚举阶段的时间复杂度为 `O(n^3)`：边界线对有 `O(n^2)` 个，每个候选点需要检查 `O(n)` 个约束。问题一数据规模较小时，该算法比复杂的半平面交实现更容易复核。

若需要处理大量观测，可将该模块替换成按边界方向排序的标准半平面交算法，将复杂度降为 `O(n log n)`，后续直径算法不变。

### 4.2 空集和无界情形

- 若不存在满足全部约束的边界交点，则观测扇形没有公共定位区域，应检查输入、数值误差或多源观测是否发生错误关联。
- 若存在非零方向 `d`，使所有半平面法向量均满足 `a_j d_x+b_j d_y>=0`，则沿该方向可以无限移动而不离开定位区域，此时区域无界，直径为无穷大。
- 正常交会定位应选择具有足够交会角的多个测点，使定位区域非空且有界。

## 5. 定位区域直径

定义定位区域直径：

```text
D = max ||P-Q||, P,Q in Omega
```

由于 `Omega` 是紧凸多边形，连续函数 `||P-Q||` 的最大值一定能够取得。进一步地，最大距离必由两个多边形顶点取得。因此不需要搜索多边形内部，只需在凸包顶点上寻找最远点对。

设凸包顶点数为 `m`。程序使用旋转卡壳算法：

1. 顶点按逆时针排列。
2. 对每条边移动其对踵点，使三角形面积达到最大。
3. 检查边端点与当前对踵点之间的距离。
4. 遍历一周后得到最远顶点对及距离 `D`。

旋转卡壳阶段的时间复杂度为 `O(m)`。连同凸包 `O(m log m)`，直径计算不会成为整体瓶颈。

## 6. 直径为 D 的圆能否覆盖定位区域

结论是：**不一定。**

考虑边长为 `D` 的等边三角形。该三角形内任意两点距离的最大值为边长 `D`，所以其区域直径为 `D`。但覆盖三个顶点的最小圆是外接圆，其半径为：

```text
r* = D/sqrt(3) ~= 0.577D
```

而直径为 `D` 的圆半径只有：

```text
D/2 = 0.5D
```

由于 `D/sqrt(3)>D/2`，任何直径为 `D` 的圆都不能覆盖该等边三角形。这说明“区域直径为 `D`”不能推出“区域可被直径为 `D` 的圆覆盖”。

根据平面 Jung 定理，任意直径为 `D` 的平面集合都可以被半径不超过 `D/sqrt(3)` 的圆覆盖，且等边三角形达到该上界。这也说明题目中的直径圆半径 `D/2` 并非普遍充分。

### 6.1 对给定定位多边形的充要判据

计算多边形的最小覆盖圆半径 `r*`，则存在直径为 `D` 的圆覆盖该区域，当且仅当：

```text
r* <= D/2
```

另一方面，由于多边形中存在距离为 `D` 的一对点，任何覆盖圆的半径均不小于 `D/2`。因此上述条件实际上等价于：

```text
r* = D/2
```

这通常发生在最小覆盖圆由一对最远顶点决定时。若最小覆盖圆由三个不共线顶点共同决定，且不存在一对点互为圆的直径端点，则有 `r*>D/2`，直径圆不能覆盖定位区域。

### 6.2 可直接执行的判定

若最远顶点对为 `A`、`B`，构造圆：

```text
C_D = (A+B)/2
r_D = ||A-B||/2 = D/2
```

由于圆是凸集，只需检查所有多边形顶点 `V_k`：

```text
max ||V_k-C_D|| <= D/2
```

若成立，则整个凸多边形均被覆盖；否则存在顶点落在圆外，不能覆盖。

程序同时计算最小覆盖圆作为独立复核。最小覆盖圆采用 Welzl 随机增量算法，固定随机种子以保证结果可复现，其期望时间复杂度为 `O(m)`。

## 7. 完整算法

```text
输入：检测点 S_i、示向度 theta_i、误差上界 delta=1°
输出：定位多边形、区域直径 D、最远点对、覆盖判断

1. 对每次观测生成上下边界两个半平面。
2. 枚举任意两条边界线的交点。
3. 保留满足全部半平面约束的交点并去重。
4. 判断公共区域是空集、无界还是有界。
5. 对有界候选顶点求凸包，得到定位多边形。
6. 用旋转卡壳求最远顶点对 A、B 和区域直径 D。
7. 以 A、B 为直径端点构造半径 D/2 的圆。
8. 检查全部顶点是否位于该圆内。
9. 用 Welzl 算法计算最小覆盖圆，复核 r*=D/2 是否成立。
```

## 8. 正确性说明

1. 每个角扇形等价于两个半平面的交，故步骤 1 没有放大或缩小单次观测可行域。
2. 有界二维半平面交的每个顶点必是至少两条边界线的交点，步骤 2-3 因此不会遗漏定位多边形顶点。
3. 半平面交是凸集，候选顶点的凸包就是定位多边形。
4. 凸多边形直径由一对顶点取得，旋转卡壳可遍历全部对踵点对。
5. 圆和多边形均为凸集，所有顶点位于圆内即可推出整个多边形位于圆内。
6. 最小覆盖圆由不超过三个边界点决定，Welzl 算法能够计算该圆。

## 9. 数值稳定性

- 平行判断、半平面可行性和圆内判断分别设置容差。
- 半平面法向量均为单位向量，使可行性容差具有统一尺度。
- 候选顶点先按距离容差去重，再计算凸包。
- 示向度通过正弦和余弦直接计算，天然支持 `0°/360°` 环绕。
- 输出空集或无界状态时不伪造有限直径。

## 10. 验证方案

1. **对称交会案例**：两个测点关于 `y` 轴对称，示向度分别为 `45°` 和 `135°`，应得到关于 `y` 轴对称的四边形。
2. **单测点案例**：只有一个角扇形，区域无界，直径为无穷大。
3. **矛盾案例**：两个扇形背向且无公共点，应返回空集。
4. **跨零度案例**：示向度接近 `360°`，检查程序无角度分支错误。
5. **等边三角形案例**：验证 `r*=D/sqrt(3)>D/2`，从数值上复核反例。
6. **随机凸包案例**：将旋转卡壳结果与所有顶点对暴力枚举结果比较。

## 11. 模型边界

问题一所称“多边形定位区域”按照附录 2 的交会定位图，仅由角度扇形相交得到。题目还给出干扰源位于半径 `1800 m` 的目标圆内，以及有效接收半径不超过 `1500 m`。若将这些先验约束同时加入，定位区域边界可能包含圆弧，不再是严格多边形。

因此正文建议先按题目要求给出纯角度交会多边形算法，再在模型改进中说明：需要利用圆域或接收距离先验时，可将圆弧约束解析处理，或用误差可控的内接/外切正多边形逼近后复用同一套算法。
